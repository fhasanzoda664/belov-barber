# Белов · Барбер — Telegram Mini App

Онлайн-запись к барберу внутри Telegram-бота + админ-панель для мастера.
Без платного хостинга: приложение на **GitHub Pages**, база на **Google Таблице**, сервер на **Google Apps Script**.

## Файлы
| Файл | Что это |
|---|---|
| `index.html`, `styles.css`, `app.js` | Само приложение (клиент + админка) |
| `config.js` | Имя, адрес, телефон, Telegram мастера, адрес сервера (`API_URL`) |
| `apps-script/Code.gs` | Сервер: копируется в Google Apps Script |

Пока `API_URL` пустой, приложение работает в **демо-режиме** (данные примерные, хранятся в браузере).

## Запуск (порядок)
1. **GitHub Pages**: публикуем папку → адрес вида `https://<логин>.github.io/belov-barber/`.
2. **Бот**: в Telegram → @BotFather → `/newbot` → получить токен (никому не показывать).
   Затем `/mybots` → бот → *Bot Settings* → *Menu Button* → вставить адрес из шага 1.
3. **Google Таблица**: создать таблицу → *Расширения → Apps Script* → вставить `Code.gs`.
   - *Настройки проекта*: часовой пояс `Asia/Dushanbe`; *Свойства скрипта*: `BOT_TOKEN`, `ADMIN_ID`, `MINI_APP_URL`.
   - Запустить функцию `setup` (разрешить доступ), затем `testMessage`.
   - *Развернуть → Новое развертывание → Веб-приложение*: «Выполнять от: меня», «Доступ: все». Скопировать URL.
4. Вписать этот URL в `config.js` → `API_URL` и снова опубликовать на GitHub.

`ADMIN_ID` — числовой Telegram ID Белова (узнать можно у бота @userinfobot). Белов должен один раз нажать /start в вашем боте.
